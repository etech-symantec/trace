🛰️ ProxySG 직접 연결 분석

브라우저에서 SSH/HTTPS를 직접 처리하지 않고, PC의 로컬 Trace Editor가 ProxySG에 연결합니다. Launcher가 설치되어 있지 않으면 실행 버튼에서 자동으로 설치 안내로 전환됩니다.
1. 장비 설정SSH 및 Management HTTPS 정보를 설정합니다.
2. Trace 정책조건을 지정하고 Local Policy에 Trace CPL을 적용합니다. 테스트 완료 후에는 추가했던 Trace 정책을 삭제할 수도 있습니다.
3. LIVE TraceHTTPS로 Trace와 Access Log를 실시간 조회합니다.
4. 즉시 분석Verdict, Method, 응답코드, Timing 기준으로 바로 분석합니다.

🚀 Trace Editor 실행

설치된 Launcher를 자동 확인합니다. 설치되지 않았다면 안정성/기능 안내 모달을 표시하고 설치 파일 다운로드를 시작합니다.

🔐 로컬 실행 구조

Launcher 상태 확인은 127.0.0.1에서만 이루어집니다. 장비 접속 정보는 Launcher가 수집하거나 웹 서버로 전달하지 않습니다. Editor 업데이트 파일은 SHA-256을 확인한 뒤 실행합니다.

처음 설치할 때 Windows SmartScreen이 표시될 수 있습니다. 현재 Launcher는 상용 코드 서명 인증서로 서명되지 않았기 때문이며, 설치 모달에서 설치 위치·무결성 검증 방식·기능을 확인할 수 있습니다.
